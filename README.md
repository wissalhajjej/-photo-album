# 📷 Photo Album

A responsive photo gallery web application built as a school project.

## 🌟 Features
- Responsive photo grid layout
- Hover animations on photo cards
- Hero section with call-to-action buttons
- Clean and modern UI design
- Mobile friendly

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Google Fonts (Poppins & Playfair Display)

## 🚀 How to Run
1. Clone the repository
2. Open index.html in your browser
3. Enjoy the gallery!
